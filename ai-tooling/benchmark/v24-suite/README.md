# Cangjie v24 public benchmark

This is a four-task, CPU-only benchmark for Cangjie 1.1.3. Each task is
standalone, dependency-free, and asks the candidate to replace exactly one
`starter/src/*.cj` file. Each public test is compiled with that source as a
separate native program, so test processes do not share state.

The contracts are new and orthogonal across the suite:

1. `01-windowed-attention` computes stable local attention over flattened
   multi-dimensional query/key/value tensors.
2. `02-softmax-trainer` performs mean-gradient minibatch softmax training
   with transactional parameter state and reset/snapshot behavior.
3. `03-event-batch-parser` parses variable-length strict-ASCII event rows
   into an atomic bounded log.
4. `04-state-snapshot` encodes and decodes a canonical, ordered integer state
   snapshot with strict framing and ownership checks.

`public-suite.json` is the closed machine-readable manifest and
`suite.schema.json` describes its schema. `COVERAGE.md` records capability and
novelty witnesses. `CALIBRATION.md` records the checked-in starter baseline
and the independently compiled reference baseline.

Validate the public tree, APIs, exact inventory, SHA-256 records, and
reproducible aggregate with:

```powershell
pwsh -NoProfile -File .\scripts\Validate-V24PublicSuite.ps1
```

Build each starter and run its four public tests with explicit Cangjie 1.1.3
paths:

```powershell
$cjpm = (Get-Command cjpm -CommandType Application).Source
$cjc = (Get-Command cjc -CommandType Application).Source
pwsh -NoProfile -File .\scripts\Invoke-PublicCalibration.ps1 -CjpmPath $cjpm -CjcPath $cjc
```

The calibration script removes generated `x`, `target`, `t`, `build`,
`cjpm.lock`, and native binaries in a `finally` block. No public file or
reference source is generated by calibration.

The manifest excludes `public-suite.json` from its file records. Its
aggregate is the lowercase SHA-256 of UTF-8 LF-ended lines containing the
manifest digest followed by the ordinal-sorted path/tab/declared-digest
records. Reversing record insertion order must reproduce the same aggregate.
